# Docs

`brand-book.html` is the source of truth for visual and voice decisions
for Erwin Public — Academic. Re-read it whenever a UI choice is in
question; the brand book wins.

`brand-book.styles.css` is the implementation reference for the brand
book itself. The product's own tokens live in `src/app/globals.css`.

Original design URL:
https://api.anthropic.com/v1/design/h/kVNHEODw3rU3fpl2DH4YgQ?open_file=Erwin+Public+-+Brand+System.html

Section map (numbered as in the book):
- 01 The Mark — circle + horizon, sun above
- 02 Color — six tool hues + paper spine
- 03 Typography — Source Serif 4, Public Sans, JetBrains Mono
- 04 Voice & Tone — plain, generous, never condescending
- 05 Components — 2px radius, no shadows, hierarchy from type and rules
- 06 Construction — clear-space and lockup rules for the mark
- 07 Tools in Practice — six sample tool screens
